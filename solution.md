## Setup & Usage

### Ranning locally

1. clone the repository:
   ~~~sh
   git clone https://github.com/Shaheen8954/online_shop.git
   cd online_shop
   ~~~

2. Install dependencies.

   ```bash
   npm install
   ```
3. Run the development server
   ~~~bash
   npm run dev 
   ~~~
your online_shop will be available on http://localhost:5173/

4. Build & Diploy
   To generate a production-ready build, run:
  
   ```bash
   npm build
   ```
